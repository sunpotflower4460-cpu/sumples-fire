## 1. 公開URL（手動で確認・差し替え）

App Store Connect には **公開された https の URL** が必要です。`wrangler deploy`（Cloudflare）または Vercel で公開後、次を登録してください。

- プライバシーポリシーURL: `https://<公開ドメイン>/privacy.html`
- サポートURL: `https://<公開ドメイン>/support.html`
- マーケティングURL（任意）: `https://<公開ドメイン>/`

サポートページの連絡先は GitHub Issues と App Store レビューです。メールアドレスなどの連絡先を載せたい場合は `public/support.html` に追記してください（個人情報のため自動では入れていません）。

### プロモーションテキスト（170文字以内）

> やりたくないタスクを書いて、終わったらFire。タスクが燃えて炭になり、炭ポイントとして積み上がります。アカウント登録も通信も不要。まずは1つ、燃やしてみませんか。

### 説明文

```
Fire Task は、先延ばししていること、面倒なこと、やりたくないことを「終わったら燃やして」片づけるタスクアプリです。

■ 書く：名前だけで追加できる
タスクは名前だけで追加できます。「最初の一歩」を添えると、取りかかる最初の行動が一目でわかります。

■ 選ぶ：緊急度と重要度で自動で並ぶ
緊急度と重要度を選ぶと4つの象限に自動分類され、今日の火種（いちばん最初に燃やすタスク）が見つかります。

■ 燃やす：終わったら Fire
完了したら「Fire」ボタンで燃やします。炎の演出とサウンドとともに、タスクは炭になり、炭ポイントとして積み上がります。うっかり押しても「元に戻す」で取り消せます。

■ 積み上がる：炭の記録と焚き火の成長
燃やしたタスクは炭の記録に残ります。炭ポイントが貯まるほど焚き火が育ち、連続日数も記録されます。

■ 安心して使える
・アカウント登録不要、広告なし、課金なし
・入力した内容は端末内にのみ保存され、外部へ送信されません
・Fire のサウンドは設定からオフにできます
・文字サイズの拡大や、視差・動きを減らす設定にも対応

やることを増やすためではなく、終わらせた気持ちよさを味わうためのアプリです。
```

## 6. 審査メモ（App Review Information）

サインイン情報: **不要**（ログイン機能なし）。

```
Fire Task はアカウント不要・オフラインで動作するタスク管理アプリです。外部サーバーとの通信、広告、アプリ内課金、トラッキングは一切ありません。

【確認手順】
1. 起動後「最初のタスクを書く」をタップし、タスク名を入力して「タスクを薪にする」をタップ
2. ホームの「完了したら Fire」をタップすると、燃焼の演出（サウンド付き。設定でオフ可）の後に炭ポイントが加算されます。直後に「元に戻す」で取り消せます
3. 下部タブの「炭」で燃やした記録、「設定」でサウンド切替・使い方・プライバシーポリシー・サポート情報を確認できます

データは端末内（WebView のローカルストレージ）にのみ保存され、外部送信されません。
```

補足（Guideline 4.2 への備え）: 単なる Web サイトの表示ではなく、端末内保存・Web Audio による合成サウンド・独自の燃焼演出・ジェスチャ操作（シートのドラッグ、タップ演出）など、アプリ固有の体験を提供しています。必要なら審査メモに追記してください。

## 8. Xcode での提出手順（手動）

```bash
npm ci
npm run lint && npm run typecheck && npm test
npm run ios:sync      # build + cap sync（ios/App/App/public と capacitor.config.json を生成）
npm run ios:open      # Xcode を開く
```

Xcode で:

1. `App` ターゲット → **Signing & Capabilities** → Team を自分の Apple Developer Team に設定（Automatically manage signing）
2. Bundle Identifier が `com.sunpotflower.sumplesfire` であることを確認（変更する場合は App Store Connect の Bundle ID と一致させる）
3. **General**: Version `1.0` / Build `1`（再提出ごとに Build を増やす）、Deployment Target `iOS 15.0`、Device Orientation は Portrait のみ、Devices は iPhone
4. 実機でスモークテスト（下記チェックリスト）
5. Scheme を `Any iOS Device (arm64)` にして **Product → Archive**
6. Organizer → **Distribute App → App Store Connect → Upload**
7. App Store Connect で TestFlight 確認後、ビルドを選択して「審査へ提出」

## 9. 実機スモークテスト

- [ ] 初回起動で白フラッシュがなく、ダークの Launch 画面から本画面へ切り替わる
- [ ] タスク追加 → Fire → 元に戻す → 炭タブで確認
- [ ] 機内モードでも動く
- [ ] アプリを完全終了して再起動してもタスクが残る
- [ ] 設定 → プライバシーポリシー/サポート → 「アプリに戻る」で戻れる
- [ ] サイレントスイッチ・音量ゼロ時に不自然な音が鳴らない / 設定でサウンドをオフにできる
- [ ] 設定アプリで文字サイズを最大にしてもレイアウトが崩れない
- [ ] ホームインジケータやダイナミックアイランドに UI が被らない
- [ ] 設定 → 一般 → 画面表示と明るさ を「ライト」にしても、アプリの見た目が同じ（ダーク）

## 10. 既知の注意点

- データは WebView のローカルストレージ保存です。アプリ削除で消えます（アプリ内・ポリシーに明記済み）。将来、端末の空き容量逼迫時の消失リスクまで抑えたい場合は `docs/CAPACITOR_NEXT_STEPS.md` の `CapacitorPreferencesDriver` 導入を検討してください。
- `npm run lint` に `useFireSeeds.ts` の `exhaustive-deps` 警告が 1 件あります。日付またぎで再計算するための意図的な依存のため、動作上の問題はありません。
