# 実機リリース確認チェックリスト — Fire Task

自動テスト（Vitest / Playwright WebKit / Simulator）で確認できない、実機でしか分からない点を中心に、上から順に 15〜20 分で確認します。
各手順の「→」が期待結果です。1つでも違ったら、その番号をメモして止めてください。

準備: Xcode で Team を選び、iPhone を接続して `App` スキームを Release で実行（または TestFlight からインストール）。

## A. 初回起動（2分）

1. iPhone に以前の Fire Task / Sumples Fire が入っていれば、先に削除する
2. アプリを起動する
   → 炎のスプラッシュのあと、「嫌なタスクを、燃やして終わらせる。」の画面が出る。白い画面が 1 秒以上続かない
3. ホーム画面に戻ってアイコンを見る
   → 炎のアイコン、名前は「Fire Task」。角の余白や枠線がない
4. もう一度アプリを開き、画面の上下を見る
   → 時刻・Dynamic Island・ホームインジケータに文字やボタンが重ならない

## B. タスクを書く（3分）

5. 「最初のタスクを書く」をタップ
   → 下からシートが開き、キーボードが出る。入力欄は明るい背景で、打った文字がはっきり読める
6. 日本語入力で「請求書を送る」と入力（変換候補で確定）
7. 「最初の一歩」に「金額だけ確認する」と入力
   → キーボードで入力欄が隠れない。「タスクを薪にする」ボタンが押せる位置にある
8. 「タスクを薪にする」をタップ
   → シートが閉じ、「今日の火種」に「請求書を送る」、その下に「まずこれだけ 金額だけ確認する」
9. 右下の「＋」→ 何も入力せず「タスクを薪にする」
   → 「タスク名を入力してください」が出て、シートは閉じない
10. シートを指で下にスワイプ
    → シートが閉じる。タスクは増えていない
11. 「＋」から「部屋を片付ける」「メールを返す」を追加
    → 「その次のタスク」に並び、4象限が 2×2 で表示される

## C. Fire（4分）

12. 「今日の火種」の「完了したら Fire」をタップ
    → 約3秒の燃焼演出。効果音が鳴る（マナーモードでない場合）。演出中は他のボタンが反応しない
13. 演出の終了を待つ
    → 「Fire完了！ +5炭になりました」と「元に戻す」が下に出る
14. 「元に戻す」をタップ
    → タスクが「今日の火種」に戻る
15. もう一度 Fire し、演出中に「完了したら Fire」の位置を素早く 3 回タップ
    → 演出は1回だけ。終了後、炭タブの合計は +5 だけ増えている
16. Fire 直後、演出中にホームボタン相当の操作（上スワイプ）でホームに戻り、5 秒後にアプリに戻る
    → 固まらず、演出が終わっているかタスクが燃焼済みになっている。二重に燃えていない
17. iPhone の横のスイッチ（または コントロールセンター）でマナーモードにして Fire
    → 効果音が鳴るかどうかを記録（鳴っても不具合ではないが、気になるなら報告）

## D. 炭・設定（3分）

18. 「炭」タブ
    → 積み上がった炭の合計と、燃やしたタスクが新しい順に並ぶ
19. 燃やした記録のゴミ箱 → 「記録を残す」
    → 何も消えない
20. もう一度ゴミ箱 → 「炭ごと削除」
    → その記録が消え、合計が減る
21. 「設定」タブ → 「Fireサウンド」をタップしてオフ
    → 「オフ」表示。次の Fire で音が鳴らない
22. 「プライバシーポリシー」をタップ
    → 文字が画面上端に食い込まずに読める。「← アプリに戻る」でアプリに戻れる
23. 「サポート情報」→ GitHub の URL をタップ
    → Safari が開く（アプリ内に GitHub が表示されない）。アプリに戻ると元の画面

## E. 保存（3分）

24. アプリスイッチャーから Fire Task を上にスワイプして終了 → 再度起動
    → タスク・炭・サウンド設定がそのまま残っている
25. iPhone を再起動 → アプリを起動
    → 同じく全部残っている

## F. 表示（3分）

26. 設定アプリ → 画面表示と明るさ → ダーク → Fire Task に戻る
    → 暗い配色になり、見出し・タスク名・ボタンがすべて読める
27. ライトに戻す
    → 見出し「今日燃やす」やタスク名が濃い色で読める
28. 設定アプリ → アクセシビリティ → 動作 → 「視差効果を減らす」をオン → Fire
    → 演出が約1秒の控えめなものになる
29. 設定アプリ → アクセシビリティ → 画面表示とテキストサイズ → 「さらに大きな文字」で最大付近にする → Fire Task を開く
    → 文字は大きくならない場合がある（WebView のため）。レイアウトが崩れて操作不能にならないことだけ確認
30. 60文字近い長いタスク名を追加
    → 横スクロールが出ない。カード内で折り返される
