# 炎のエフェクトと音（リアル化の仕組み）

外部の画像・動画・音源ファイルは一切使わず、すべてコードで生成しています（ライセンス上の懸念なし・通信なし）。

## 炎の描画（GPU）

- `src/lib/fireShader.ts` — WebGL1 のフラグメントシェーダ。ドメインワープした fbm ノイズを上向きに流し、温度→色（黒体放射風）に変換します。
  - 縦に伸びる筋状の乱流（x 方向の周波数を高く）／場所ごとに高さが違う複数の舌／上ほど千切れる先端
  - 内部も乱流で濃淡が変わり、根元だけが白熱（上は赤く半透明）
  - 地面への照り返し、着火フレア、冷めた場所にだけ出る煙
  - 特殊な炎（鬼火・黄金・桜…）は `paletteFromColors()` で同じ炎を別の色で描画
- `src/lib/emberField.ts` — 火の粉の物理（浮力・乱流・冷却で黄→橙→赤）。
- `src/lib/fireIntensity.ts` — 燃焼演出の時間変化（着火→燃焼→収束→解放）と焚き火の段階ごとの強さ。音の時間割（`BURN_TIMING`）と同じ時計。
- `src/components/FireCanvas.tsx` — 上記をまとめた描画コンポーネント。
  - 画面外では停止、フレームレート上限、フレーム時間が長いと解像度を自動で下げる（最小 0.45 倍）
  - アンマウントで WebGL コンテキストを即解放（連続 Fire でも上限に達しない）
  - WebGL が使えない場合は従来の CSS 炎に自動フォールバック
  - 省モーション設定では静止画1枚のみ描画
- 使用箇所: 燃焼演出（`BurningRitual`）、焚き火カード（`FireCampfire`、タップでつつける）

調整したいとき: 炎の形・色は `FRAGMENT` 内の `reach` / `field` / `hot`、強さの時間変化は `fireIntensity.ts`、解像度・負荷は `FireCanvas` の `resolution` / `fps`。

## 音（サンプル単位で合成）

`src/lib/fireSynth.ts` が焚き火の音を 4 層で合成します（Web Audio に依存しない純関数）。

1. **唸り** — 低音のうねり・胸に響く中低域・空気の流れる音。3 帯域がそれぞれ別のリズムでランダムに強弱（固定の LFO ではない）
2. **パチパチ** — ポアソン分布で不規則に発生。小さな「プチ」（tick）、木が弾ける低い「ポン」（pop）、鋭い「パン」（snap）。連鎖して鳴り、音量は対数正規分布（小さい音が多く、時々鋭く突き抜ける）、パンニングと微小遅延でステレオに広がる
3. **着火** — ガスに火が付く「ボッ」：開いて閉じるフィルタ付きノイズ＋下がっていくサブ低音＋鋭い着火音
4. **冷却** — 火勢が落ちるにつれヒス音が増え、パチパチがまばらになって静かに消える

`src/lib/fireSoundEngine.ts` が合成結果をバッファとして再生します（小部屋のリバーブ付き、完了時はベルのアルペジオ）。合成は重い（約0.1秒）ため、アイドル時間に先行生成してプールし、タップ時に待たせません。毎回シードが変わるので同じ音が繰り返されません。

### 検証方法について

音は耳では確認できていないため、次の方法で構造を検証しています（`src/lib/fireSynth.test.ts`）。最終的な聴感の調整は実機で行ってください。

- 決定性（同じシード→同じ音）と有限値・ピーク制御
- パチパチの鋭さ（2 kHz 以上の包絡の尖度）が定常ノイズより大きいこと
- 着火で盛り上がり、冷却で下がり、終端で無音になること
- エネルギーの大半が 2 kHz 未満にあること（シャーという雑音ではなく唸りであること）

聴感を調整したい場合は `fireSynth.ts` の `gRumble` / `gBody` / `gWhoosh` / `gHiss`（各層の音量）、`crackleRate()`（パチパチの密度）、`levelDb`（パチパチの音量分布）を変更してください。
