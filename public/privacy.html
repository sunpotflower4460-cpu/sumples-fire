Fire Task プライバシーポリシー

更新日 2026年11月28日

1. 取得・保存する情報

Fire Task は、入力したタスクとメモ、タスクの優先度や重さ、完了の記録と炭ポイント、連続日数、表示や音の設定を保存します。Fire Task Plus の炎、焚き火の景色、音量、マイセットなどの設定も端末内に保存します。

これらはすべてお使いの端末内に保存されます。

  • iPhone アプリ版: アプリ専用の端末内保存領域に保存します。他のアプリからは読み取れません。
  • Web 版: お使いのブラウザの端末内ストレージ（localStorage）に保存します。

氏名、メールアドレス、電話番号、位置情報、連絡先、写真、端末識別子などを取得する機能はありません。アカウント登録も不要です。

2. 外部送信・第三者提供

入力したタスクや記録を、開発者や第三者のサーバーへ送信する機能はありません。

本アプリは、広告、アクセス解析、クラッシュ解析、トラッキングを目的とした SDK や外部サービスを利用していません。ユーザーを追跡（トラッキング）することもありません。

iPhone アプリ版のタスク管理・Fire・炭の記録はオフラインで使えます。アプリの効果音と環境音は端末内で合成します。マイクへのアクセスは求めません。

Fire Task Plus の価格取得、購入、購入状況の確認、復元は、Apple の App Store 購入機能（StoreKit）で処理されます。タスクや記録は購入処理に送信されません。開発者は Apple Account の認証情報や支払い情報を取得しません。Apple による情報の扱いは Apple のプライバシー情報をご確認ください。

Web 版（sumples-fire.vercel.app）をブラウザで開いた場合に限り、ページ配信のためホスティング事業者（Vercel Inc.）が IP アドレスやブラウザ情報などの一般的なアクセスログを記録することがあります。入力したタスク内容は送信されません。

3. データの削除

タスクと記録は、アプリ内の「削除」から削除できます。iPhone からアプリを削除すると、その端末のアプリ内保存データも削除されます。OS のバックアップは端末の設定に従います。Web 版の保存データはブラウザのサイトデータから削除できます。

開発者は端末内の記録を閲覧・復元できません。「購入を復元」で戻るのは Plus の利用権です。

4. お子さまの利用

アプリにアカウント登録はありません。アプリ内購入には Apple Account と端末の購入制限が適用されます。

5. ポリシーの変更

情報の扱いが変わる場合は、本ポリシーを更新し、このページでお知らせします。

6. お問い合わせ

本ポリシーに関するお問い合わせは、サポートページに記載の方法でご連絡ください。
