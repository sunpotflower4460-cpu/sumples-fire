Fire Task プライバシーポリシー

最終更新日: 2026-09-24

1. 取得・保存する情報

Fire Task が保存するのは、ユーザーが入力したタスク（タスク名、最初の一歩、メモ、カテゴリ、緊急度・重要度、重さ）と、燃やした記録（炭ポイント、連続日数）、効果音のオン/オフ設定だけです。

これらはすべてお使いの端末内に保存されます。

  • iPhone アプリ版: アプリ専用の端末内保存領域に保存します。他のアプリからは読み取れません。
  • Web 版: お使いのブラウザの端末内ストレージ（localStorage）に保存します。

氏名、メールアドレス、電話番号、位置情報、連絡先、写真、端末識別子などを取得する機能はありません。アカウント登録も不要です。

2. 外部送信・第三者提供

入力したタスクや記録を、開発者や第三者のサーバーへ送信する機能はありません。

本アプリは、広告、アクセス解析、クラッシュ解析、トラッキングを目的とした SDK や外部サービスを利用していません。ユーザーを追跡（トラッキング）することもありません。

iPhone アプリ版は、動作のためにインターネット通信を行いません。効果音も端末内で合成しており、マイクは使用しません。

Web 版（sumples-fire.vercel.app）をブラウザで開いた場合に限り、ページ配信のためホスティング事業者（Vercel Inc.）が IP アドレスやブラウザ情報などの一般的なアクセスログを記録することがあります。入力したタスク内容は送信されません。

3. データの削除

各タスクはアプリ内の「削除」からいつでも削除できます。iPhone アプリ版では、アプリを削除すると保存データもすべて削除されます。Web 版では、ブラウザのサイトデータを削除すると保存データも削除されます。

データは端末内にのみあるため、開発者がユーザーのデータを閲覧・復元することはできません。

4. お子さまの利用

本アプリは個人情報を取得しないため、年齢にかかわらず同じ内容で利用できます。

5. ポリシーの変更

将来、外部通信やアカウント機能などを追加する場合は、事前に本ポリシーを更新し、このページでお知らせします。

6. お問い合わせ

本ポリシーに関するお問い合わせは、サポートページに記載の方法でご連絡ください。
