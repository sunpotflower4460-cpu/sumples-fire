Fire Task サポート

更新日 2026年11月28日

アプリ概要

Fire Task は、やりたくないタスクを書いておき、終えたら「Fire」して燃やすタスクアプリです。燃やしたタスクは炭ポイントとして記録に残ります。

基本の使い方

  1. 右下の「＋」ボタンから、燃やしたいタスクを書きます。初回は「例のタスクを入れて試す」で、燃やす前の例を3つ入れて始めることもできます（不要なものは削除できます）。
  2. 必要なら「優先度と重さ」を調整します。緊急度と重要度から、燃やす順番が自動で並びます。
  3. 終わったら「完了したら Fire」を押します。燃焼演出のあと、炭ポイントが加算されます。
  4. 押し間違えた場合は、直後に表示される「元に戻す」で取り消せます。

よくある質問

Q. データはどこに保存されますか？
この端末内に保存されます。アカウント登録やログインは不要です。

Q. 機種変更やアプリの再インストールでデータは引き継げますか？
Fire Task にはタスクを同期するアカウントや引き継ぎ機能がありません。アプリを削除すると、その端末のアプリ内保存データも削除されます。OS のバックアップは端末の設定に従います。

Q. 効果音を消したいです。
「設定」タブの「Fireサウンド」をオフにしてください。

Q. 燃焼演出が長い・まぶしいと感じます。
iPhone の「設定」→「アクセシビリティ」→「動作」→「視差効果を減らす」をオンにすると、演出が短く控えめになります。

Fire Task Plus

iPhone アプリの「設定」→「Fire Task Plus」から内容を確認できます。Plus は買い切りです。価格は購入画面に表示され、タスクの追加、Fire、炭の記録は無料で使えます。

購入時と同じ Apple Account で「設定」→「購入を復元」を押すと、Plus の利用権を復元できます。タスクデータは端末の保存状態に従います。

Apple の購入履歴の確認や返金の申請は Apple サポートをご利用ください。

お問い合わせ

操作の質問や不具合は GitHub Issues で開発者にお知らせください。投稿には GitHub アカウントが必要です。

不具合の報告には、iPhone のモデル、iOS とアプリのバージョン、発生までの操作を添えてください。投稿は公開されるため、個人情報、タスクの内容、購入の領収書は記載しないでください。
